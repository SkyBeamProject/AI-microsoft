# Overview

An index of Microsoft's open-source AI repositories, organized as git submodules in three tiers: AI100 samples (Azure ML SDK, Cognitive Services, Intelligent Kiosk, MMLSpark), AI200 reference architectures (real-time and batch scoring for classic ML and deep learning on Kubernetes, Pipelines, Databricks, and Batch AI), and AI300 best practices (Computer Vision, NLP, Recommenders, MLOps). Clone with `--recurse-submodules` to fetch everything or pull individual submodules as needed.
